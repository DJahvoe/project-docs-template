# API-001 – Create User

## Base URI
- Base URI: `/api`
- Endpoint: `POST /users`
- Full Path: `/api/users`

## Purpose
Create a new user record in the system.

Typical use cases:
- User sign-up flow
- Admin creates a new user
- System-to-system user provisioning

## Authentication
- Required: Yes
- Type: Bearer Token (JWT or equivalent)

## Request

### Headers
Content-Type: application/json
Accept: application/json


### Body
```json
{
  "email": "user@example.com",
  "name": "John Doe"
}
```

| Field | Type   | Required | Rules                                             |
| ----- | ------ | -------- | ------------------------------------------------- |
| email | string | Yes      | Valid email format, max 254 chars, must be unique |
| name  | string | Yes      | 1–100 chars, trimmed                              |

## Response
### Success (201 Created)
```json
{
  "id": "3c3a7d16-2f6d-4f3b-9f3d-1b2c3d4e5f60",
  "email": "user@example.com",
  "name": "John Doe",
  "status": "ACTIVE",
  "createdAt": "2025-12-17T10:00:00Z"
}
```

### Error Format
```json
{
  "errorCode": "ERROR_CODE",
  "message": "Human-readable message"
}
```

## Edge Cases / Errors
### 400 Bad Request (Validation Error)

Occurs when:
- Required fields are missing
- Email format is invalid
- Name is empty or too long

```json
{
  "errorCode": "INVALID_REQUEST",
  "message": "Email format is invalid"
}
```

### 409 Conflict (Duplicate Email)

Occurs when:

A user with the same email already exists

```json
{
  "errorCode": "USER_ALREADY_EXISTS",
  "message": "User with this email already exists"
}
```

### 401 Unauthorized

Occurs when:

Authorization is missing or invalid

```json
{
  "errorCode": "UNAUTHORIZED",
  "message": "Authentication is required"
}
```

### 403 Forbidden

Occurs when:

Authenticated user lacks permission
```json
{
  "errorCode": "FORBIDDEN",
  "message": "You do not have permission to perform this action"
}
```

### 413 Payload Too Large

Occurs when:

Request body exceeds server limits
```json
{
  "errorCode": "PAYLOAD_TOO_LARGE",
  "message": "Request body is too large"
}
```
### 500 Internal Server Error

Occurs when:

Unexpected server failure
```json
{
  "errorCode": "INTERNAL_ERROR",
  "message": "Unexpected server error"
}
```

### Business Rules

- Email must be globally unique
- Newly created users default to status = ACTIVE
- createdAt is generated by the server (UTC, ISO-8601)
