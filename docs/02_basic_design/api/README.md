# API Design

## Purpose
This folder defines the detailed API specifications for the system.

Each API is documented in an individual Markdown file so that:
- APIs can be reviewed independently
- Changes are traceable in Git
- Test cases can reference API IDs

This documentation is the **source of truth** for backend and frontend integration.

---

## Scope
This folder includes:
- Endpoint definitions
- Request / response structures
- Validation rules
- Error responses
- Authentication and authorization requirements

This folder does NOT include:
- Implementation code
- Unit test code (see `05_unit_testing`)
- Infrastructure configuration
